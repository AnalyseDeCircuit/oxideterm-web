These are the default shortcuts for common actions. Open **Settings → Keybindings** to inspect or change the current bindings, including plugin commands. Customized bindings take precedence over this reference.

## Application & Window

| Action | macOS | Windows / Linux |
|--------|-------|-----------------|
| New Local Terminal | `⌘ T` | `Ctrl+T` |
| Shell Selector | `⌘ ⇧T` | `Ctrl+Shift+T` |
| New SSH Connection | `⌘ N` | `Ctrl+N` |
| Close Current Tab | `⌘ W` | `Ctrl+W` |
| Next Tab | `⌘ }` | `Ctrl+Tab` |
| Previous Tab | `⌘ {` | `Ctrl+Shift+Tab` |
| Jump to Tab 1–9 | `⌘ 1`–`⌘ 9` | `Ctrl+1`–`Ctrl+9` |
| Command Palette | `⌘ K` | `Ctrl+K` |
| Toggle Sidebar | `⌘ \` | `Ctrl+\` |
| Open Settings | `⌘ ,` | `Ctrl+,` |
| Zen Mode | `⌘ ⇧Z` | `Ctrl+Shift+Z` |
| Keyboard Shortcuts Help | `⌘ /` | `Ctrl+/` |

### Command Palette Extras

| Action | macOS | Windows / Linux |

| Broadcast Input | `⌘ B` | `Ctrl+Shift+B` |

## Terminal (In-Terminal)

These shortcuts work when a terminal pane is focused:

| Action | macOS | Windows / Linux |
|--------|-------|-----------------|
| Search | `⌘ F` | `Ctrl+Shift+F` |
| Clear Screen | `Ctrl+Shift+L` | `Ctrl+Shift+L` |
| Inline AI Panel | `⌘ I` | `Ctrl+Shift+I` |
| Close Panel | `Esc` | `Esc` |
| Copy | `⌘ C` | `Ctrl+Shift+C` (or auto-copy on select) |
| Paste | `⌘ V` | `Ctrl+Shift+V` (or right-click) |

:::note
`Ctrl+L` remains available to the shell for clearing and redrawing its prompt. The application's Clear Screen action uses `Ctrl+Shift+L` on all platforms.
:::

## Tips

- The **Command Palette** (`⌘K` / `Ctrl+K`) provides fuzzy search across all available actions — use it when you forget a shortcut.
- **Settings → Keybindings** shows the current bindings and their action scopes.
- Some terminal-focused shortcuts differ between platforms because OxideTerm avoids intercepting common shell keybindings (like `Ctrl+C` for SIGINT).
