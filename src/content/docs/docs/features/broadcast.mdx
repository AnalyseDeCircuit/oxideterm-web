---
title: Broadcast Input
description: Send terminal input and command-bar commands to selected terminal targets.
---

**Broadcast Input** forwards supported keyboard input, pasted text, and command-bar commands to selected terminal targets. Targets can be in different tabs or split panes.

## Select Targets

Open the broadcast control in the terminal command bar. Enable broadcasting and choose the destination sessions using the available target selector or a saved broadcast group. Review the displayed destinations before typing.

The selection defines **receivers**, not a closed group of senders. While broadcasting is enabled, input from the current terminal can reach the selected receivers even if the current terminal is outside that group. The source pane is excluded from duplicate delivery.

## Working with Groups

The current implementation uses one active broadcast selection. Saved groups let you recall a set of targets; they do not create multiple independent synchronization channels. Do not assume that switching to another tab isolates its input, or that two shell panes on the same saved connection can always be selected independently through a connection-based group.

For a one-host change, disable broadcasting before typing, then enable it again when all destinations are ready. Closing a pane removes it from the live target set.

## Terminal and Command Bar

Direct terminal input is broadcast as well as command-bar submissions. Each destination receives input through its own terminal session and interprets it according to its current shell or application state. Different prompts, directories, or editor positions can produce different results from the same input.

:::caution
Broadcast input is delivered immediately. Disable it before typing into an unrelated session, entering credentials, or making a change intended for only one host. Selecting a group does not restrict which terminal can act as the sender.
:::

Broadcast can be used with [split panes](/docs/features/terminal/) to watch each destination while running shared checks or deployment commands.
