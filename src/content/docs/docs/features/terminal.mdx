OxideTerm's terminal is a Rust-native pipeline. Session bytes update `alacritty_terminal` state, OxideTerm builds terminal snapshots, and a GPUI painter draws text, selection, cursor, decorations, Sixel images, and Kitty graphics directly on the GPU surface.

There is no browser renderer or terminal bridge in this path. Input, output, resize events, search, selection, scrollback, and rendering remain inside the native process.

## Rendering Policy

The terminal drains pending events with budgets tuned for three activity tiers:

| Tier | Trigger | Behavior |
|---|---|---|
| **Boost** | The previous drain exhausted its budget | Prioritizes throughput until queued output catches up |
| **Normal** | Recent input or terminal activity | Keeps interactive typing and fresh output responsive |
| **Idle** | No recent input or output | Avoids unnecessary redraw work |

The application also supports Quality, Low Power, Compatibility, and Auto render profiles. Auto selects a policy from detected graphics capability; Compatibility disables expensive visual effects and terminal image decoding when required.

## Supported Sessions

- Local PTY sessions
- SSH terminals
- Telnet terminals
- Serial terminals
- Recorded-session playback

All session types use the same native terminal view and interaction model while their backends own protocol-specific connection and lifecycle behavior.

## Multi-Tab and Split Panes

- Open multiple tabs for local or remote sessions.
- Split terminal tabs horizontally or vertically.
- Keep independent shell channels, scroll positions, selections, and search state per pane.
- Resize panes with draggable dividers.
- Restore terminal topology as part of workspace and reconnect state.

## Command Folding and Shell Integration

Open **Settings → Terminal → Display** and enable **Command folding**. Click the button beside a completed command in the left gutter to collapse or expand its output. The command's context menu also offers **Collapse output** or **Expand output**; enable **Hover Actions** if you want those controls beside a selected command.

The gutter uses one character column and works with zero terminal padding. Folding changes the view, not the terminal output or recording. Resizing the window retains the folded command selection while the terminal recalculates line positions. **Command Marks** controls range highlighting separately from the folding switch.

Folding requires reliable command-start, output-start, and completion information from Shell integration. Running commands, incomplete boundaries, and output no longer retained in scrollback are not foldable. Enabling the display switch alone cannot reconstruct missing boundaries from old output.

### Install or Update SSH Shell Integration

1. Open the target SSH terminal.
2. Go to **Settings → Terminal → Awareness & Integration**, then check the remote Shell integration status.
3. Install, update, or repair the integration as indicated. The deployment policy can ask when needed, install automatically, or leave installation to you.
4. **Open a new SSH terminal afterward.** Existing shells keep their current hooks; updating files does not reload them.
5. Run a command that produces several lines and finishes, then try its folding control.

An outdated remote integration can trigger an update reminder when a new SSH terminal opens. Choosing **Later** leaves it unchanged; you can update manually from the same settings page.

The remote integration installs readable hooks for Bash, Zsh, Fish, Nushell, and PowerShell. If folding remains unavailable after updating and opening a new terminal, check the actual shell and whether its startup files load the integration. Prompt themes and terminal multiplexers may also affect whether complete command boundaries reach OxideTerm.

## Broadcast Input

Broadcast forwards terminal keyboard input, pasted text, and command-bar commands to selected targets in other tabs or split panes. A group defines receivers; it does not isolate input from terminals outside that group. Disable broadcasting before switching to unrelated work. See [Broadcast Input](/docs/features/broadcast/) for the current behavior.

## Terminal Search

Open search with `⌘F` on macOS or `Ctrl+Shift+F` on Windows/Linux. Native search scans the active terminal's retained scrollback, highlights matches, shows the current/total result count, and scrolls to the selected match.

Use Enter or the down arrow for the next result, Shift+Enter or the up arrow for the previous result, and Escape to close search. See [Terminal Search](/docs/features/terminal-search/) for details.

## Session Recording and Playback

OxideTerm records terminal output in asciicast v2 format:

- Timestamped output events
- Variable-speed playback
- Search within playback content
- Export for review or use with compatible asciinema tooling

## Terminal Graphics

The native terminal tracks Sixel and Kitty image assets alongside terminal state. Graphics decoding, pixel limits, placeholders, and cache size follow the active render profile so low-power or compatibility modes can reduce cost.

## Command Palette and Zen Mode

Use `⌘K` on macOS or `Ctrl+K` on Windows/Linux to open the command palette. It provides native actions for tabs, connections, settings, search, and workspace tools.

Zen mode hides surrounding workspace chrome to maximize terminal space. Background images, opacity, blur, and fit are available from Appearance settings when the selected render profile permits them.

## Connection Management

- Saved connections and active nodes appear in the session tree.
- Quick Connect opens temporary connections without requiring a saved profile.
- OpenSSH configuration and encrypted `.oxide` bundles can populate saved state.
- Multi-hop ProxyJump routes resolve through the node router.
- Password, private key, certificate, SSH Agent, and keyboard-interactive authentication are supported where applicable.
- Terminal, SFTP, forwards, and IDE consumers can share a physical SSH connection.
- Host-key TOFU rejects unexpected changes to known hosts.

## Local Shells

Local terminals use the `alacritty_terminal::tty` PTY backend, including ConPTY on Windows. Shell discovery covers common installations such as zsh, bash, fish, PowerShell, Git Bash, WSL2, and CMD according to the current platform.

## Resource and Host Tools

Active SSH nodes can feed native monitoring and [Host Tools](/docs/features/host-tools/) for latency, processes, services, containers, ports, filesystems, packages, logs, and other sampled state. These tools share node identity and reconnect state with the terminal rather than opening an unrelated workspace.

## Selection and Highlighting Controls

Terminal settings include a **hold Shift to select text** option. With it enabled, ordinary dragging remains available for terminal interaction; Shift-drag starts a text selection.

Shift-click extends an existing selection; horizontal and vertical terminal padding are independently configurable, both defaulting to **1 px**; selection-match highlighting has a global setting and a control in the existing terminal highlights panel alongside grep/rg highlighting.

## File-Transfer Protocols

Terminal transfer detection supports trzsz and lrzsz-compatible ZMODEM, XMODEM, and YMODEM workflows. Protocol data is handled before display transforms and recording. Use the transfer UI to complete or cancel a detected transfer.

Transfer detection waits for a complete trzsz handshake line and avoids treating a truncated tail of ordinary output as an X/YMODEM command.
