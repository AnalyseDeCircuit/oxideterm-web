title: 运行时

---

**运行时**是 OxideTerm 处理实时 SSH 工作的运维视图。它将此前分开的连接池、连接监控和系统健康页面整合为同一个可复用标签页，包含**概览**、**系统健康**和**连接矩阵**三个分段。右侧的**主机工具**伴随面板则使用相同的活动连接上下文，提供主机级检查和受支持的远端操作。

可从活动栏或命令面板打开**运行时**。再次打开时会复用已有的运行时标签页，并刷新当前状态。

## 概览

运行时可见时，概览会汇总受管理的 SSH 连接池：

- 按**活动**、**空闲**、**重连中**和**链路断开**分类的连接数量。
- 共享受管理 SSH 连接的终端、SFTP 和端口转发消费者总数。
- 连接池汇总信息，包括空闲超时和容量状态。

页面刻意展示聚合状态，而不是为每条连接单独建立管理卡片。连接行为应在连接设置和对应的连接工作流中配置；运行时用于观察这些配置在当前工作区中的结果。

## 系统健康

系统健康一次采样一条活动 SSH 连接。通过选择器选择目标连接后，可查看该主机实际支持的指标。

远端主机支持资源采样时，运行时可显示 CPU、内存、交换分区、磁盘、网络流量、GPU 信息、负载平均值、热点进程和 SSH 往返时间。具体可用项取决于远端操作系统、权限和支持的探针；无法进行详细采样时，运行时会退化为 SSH 往返时间，而不会虚构主机指标。

采样会针对所选活动连接启动，也可在面板中停止或重试。完整运行时页面打开时，会显示历史迷你趋势图。

## 连接矩阵

连接矩阵展示 OxideTerm 当前管理的实时 SSH 路由。直连的活动连接会显示为根节点；通过受管理跳板机打开的连接会显示在父节点下方。

```text
[ alice@bastion.example ]
              |
              v
[ alice@internal-db ]
```

连接矩阵来自当前连接注册表，而不是全部已保存连接。节点显示账户和主机；连线表示父子 SSH 路由，例如 ProxyJump 的一跳。只有活动、空闲、连接中和重连中的连接会进入矩阵；已经断开或失败的路由不会作为历史节点保留。

### 矩阵操作

| 操作 | 结果 |
| --- | --- |
| 滚轮 | 以指针位置为中心缩放。 |
| 拖拽空白画布 | 平移矩阵。 |
| 双击节点 | 打开节点操作菜单。 |
| 点击菜单外部 | 关闭菜单。 |

画布将可见状态收敛为两种信号：活动或空闲连接为**已连接**，正在建立或重建的连接为**连接中**。一条路由的两端都已连接时，二者之间的连线会更突出。它不会自行额外探测可达性，也不会保存失败历史。

每个节点菜单都可以跳转到该节点的活动会话。节点已连接时，菜单还会提供新建终端和打开 SFTP。这些操作复用现有活动连接，不会新增一个独立的路由配置页面。

## 主机工具伴随面板

主机工具是独立的右侧活动栏面板，不属于运行时分段。它与运行时共享所选活动 SSH 连接，因此排查时二者可以互补：运行时说明连接范围的状态，主机工具则检查远端主机本身。可在[主机工具](/zh-hans/docs/features/host-tools/)中查看可用模块和远端操作边界。

## 排查重连

运行时展示当前状态；**事件日志**记录生命周期时间线。连接断开时：

1. 在概览中识别受影响的连接池状态和消费者。
2. 在系统健康或[主机工具](/zh-hans/docs/features/host-tools/)中检查所选主机的可用上下文。
3. 到[事件日志](/zh-hans/docs/features/event-log/)查看重连阶段和失败详情。

连接矩阵适合在恢复前后确认实时跳板路由，但它不是断开节点的历史记录。
