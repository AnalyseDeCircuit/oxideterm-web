---
title: 主题与外观
description: 配置明暗主题、字体、背景和动效，或创建可分享的自定义配色。
---

在**设置 → 外观**中调整配色，无需重启。OxideTerm 提供 33 套内置主题，包括深色、浅色及 Dracula、Solarized、Nord、Gruvbox、Tokyo Night 等风格。

## 明暗两套方案

选择固定浅色、固定深色或跟随系统外观。明暗方案都可以分别配置应用主题和终端主题，也可以把当前外观保存为某套方案；不必开启跟随系统才能配置两套主题。

顶栏的太阳或月亮表示**当前**模式。点击后切换到另一套已配置方案。目标方案尚未配置时，应用会提示先配置，不会自动换成无关主题。

## 动效

提供**标准、快速、减少、关闭**四档。标准和快速用于侧边栏、选项高亮、弹窗、通知和控件反馈；连续切换或反向操作时，从当前状态继续过渡。

减少模式保留轻量淡入淡出，省略位移和旋转；关闭后立即更新。主题与背景切换采用轻量过渡，不以整窗闪光强调变化。

## 自定义主题

从当前主题或另一套内置主题创建配色，在预览中检查后保存。主题包含名称、稳定标识、20 个终端颜色字段和 23 个应用颜色字段。

| 部分 | 内容 |
| --- | --- |
| 终端基础色 | 背景、前景、光标、选区 |
| 终端 ANSI 色 | 8 个标准颜色及 8 个高亮颜色 |
| 应用背景 | 主背景、面板、卡片、悬停、选中等表面 |
| 应用文字与边框 | 正文、次要文字、标题、边框和分隔线 |
| 强调与状态 | 强调色、成功、警告、错误和提示 |

### 从终端配色生成应用颜色

1. 选择或编辑终端配色。
2. 在应用颜色区域使用“从终端自动衍生”。
3. 在预览中检查背景、文字、强调色和状态色。
4. 按需修改单个颜色后保存。

生成结果仍可逐项编辑。保存会立即选用该自定义主题；删除正在使用的自定义主题时，应用会返回有效的内置主题。

### 导入与导出

在外观页面把自定义主题导出为 JSON，或导入已有主题文件。导入会检查格式版本、必需颜色字段和颜色值。

主题文件只携带配色。字体、字号、行高、界面密度、动效、渲染模式和背景图片属于应用设置，不包含在主题文件中。

## 字体与显示

终端设置支持按顺序指定字体栈，并配置字号与行高。字体不可用时会提示，并使用等宽字体回退。系统已安装字体不代表应用支持其文件格式；点阵字体无法使用时，可选择可用的轮廓等宽字体并检查预览。

其他外观设置包括应用字体、密度、圆角、背景图片、透明度、模糊、适应方式和按标签显示背景。自动、质量、低功耗、兼容渲染模式独立于配色；兼容模式可能关闭部分视觉效果，便于排查渲染问题。
