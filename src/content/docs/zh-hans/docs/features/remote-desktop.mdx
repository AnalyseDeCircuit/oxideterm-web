title: 远程桌面
description: 在终端、文件与端口转发旁边打开原生 RDP 和 VNC 标签页。
---

OxideTerm 将 **RDP** 和 **VNC** 作为原生远程桌面标签页打开。它们是独立的连接类型，不属于 SSH 会话：SFTP、跳板机、SSH Agent 转发和 SSH 端口转发均不适用于它们。

## 新建连接

打开**新建连接**，然后在连接类型列表中选择 **RDP** 或 **VNC**。

| 协议 | 默认端口 | 必填连接信息 |
| --- | --- | --- |
| **RDP** | `3389` | 主机、端口、用户名和密码 |
| **VNC** | `5900` | 主机和端口；需要认证时由服务器发起请求 |

两种连接都可使用描述性名称保存，并从连接树重新打开。切换协议时会更新尚未修改的默认端口；你手动填写的自定义端口会被保留。

也可以在命令面板中使用 `rdp://主机` 或 `vnc://主机` 建立临时连接。目标未使用默认端口时，请在地址中写明端口。

## 会话中

远程桌面标签页会把键盘和鼠标输入发送给所选主机，并处理：

- 剪贴板文本；远端提供方支持时也会处理更丰富的剪贴板格式
- 远端光标更新
- 远端提供方支持时的视口调整请求
- 会话断开或失败后的手动重连

使用标签页控制项重连或关闭桌面。此前的协议帮助进程已退出时，重连会启动新的协议会话。

## 安全与网络范围

RDP 和 VNC 直接连接到你输入的端点，不会继承 SSH 连接的信任、认证或转发设置。请确认目标主机、路由、防火墙策略和远程桌面服务均符合你的组织要求。

Windows Subsystem for Linux 的图形工作负载请参阅 [WSL 图形](/zh-hans/docs/features/graphics/)。WSL 图形是独立的 Windows 专用工作流，会为 WSL 发行版启动本地 VNC 支撑的会话。
