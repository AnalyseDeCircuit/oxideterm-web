---
title: 远程桌面
description: 原生 RDP、VNC 会话、SSH 网关与独立的桌面连接设置。
---

OxideTerm 将 **RDP** 和 **VNC** 作为原生桌面标签页打开，与终端和文件操作并列。桌面协议使用自己的登录凭据，也可以选择已保存的 SSH 网关提供网络通路。

## 新建连接

打开**新建连接**，选择 **RDP** 或 **VNC**。

| 协议 | 默认端口 | 连接信息 |
| --- | --- | --- |
| **RDP** | `3389` | 主机、端口、用户名和密码 |
| **VNC** | `5900` | 主机和端口，认证要求取决于服务器 |

保存配置后可在**会话管理**中重新打开或编辑，也可以建立临时连接。命令面板支持 `rdp://主机` 和 `vnc://主机`，并可指定端口。

## SSH 网关

桌面主机需要经过 SSH 服务器访问时，选择一条已保存的 SSH 连接作为网关。OxideTerm 通过该连接建立到桌面端点的受管理隧道，所选网关可以使用自身配置的跳板链路和认证方式。

网关认证与 RDP/VNC 登录认证相互独立。桌面标签在使用期间持有隧道，关闭时释放自身消费者，不会断开仍被其他功能使用的共享 SSH 连接。

## RDP SOCKS5 代理

不经过 SSH 网关的 RDP 连接，可以在配置编辑器中选择直连、全局代理或自定义 SOCKS5 代理，支持认证、远程 DNS 和绕过规则。此 RDP 路由不支持 HTTP CONNECT。

选择 SSH 网关后，使用网关自身的路由和代理配置，不会再对本地隧道套用 RDP 代理。路由设置会保留在会话管理及受支持的云同步配置中；密码同步需单独选择，参见[连接与会话](/zh-hans/docs/features/connections/#可选凭据同步)。

## 会话中

远程桌面标签支持键盘、鼠标、远端光标、剪贴板交换，以及服务器和提供方支持的视口调整。各连接可配置受支持的重定向与显示选项。

通过标签页控制项重连或关闭桌面。此前的帮助进程已退出时，重连会建立新的协议会话。

本地 Windows Subsystem for Linux 发行版中的 Linux 图形应用，请参阅 [WSL 图形](/zh-hans/docs/features/graphics/)。这是独立的 Windows 专用 VNC 工作流。
