---
title: 快捷键
description: 应用、终端、分屏和 SFTP 常用默认快捷键，以及自定义绑定的入口。
---

以下列出常用操作的默认快捷键。打开**设置 → 快捷键**可查看和修改当前绑定，包括插件命令；自定义绑定优先于本页列出的默认值。

## 应用与窗口

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| 新建本地终端 | `⌘ T` | `Ctrl+T` |
| Shell 选择器 | `⌘ ⇧T` | `Ctrl+Shift+T` |
| 新建 SSH 连接 | `⌘ N` | `Ctrl+N` |
| 关闭当前标签 | `⌘ W` | `Ctrl+W` |
| 下一标签 | `⌘ }` | `Ctrl+Tab` |
| 上一标签 | `⌘ {` | `Ctrl+Shift+Tab` |
| 跳到第 1–9 标签 | `⌘ 1`–`⌘ 9` | `Ctrl+1`–`Ctrl+9` |
| 命令面板 | `⌘ K` | `Ctrl+K` |
| 切换侧边栏 | `⌘ \` | `Ctrl+\` |
| 打开设置 | `⌘ ,` | `Ctrl+,` |
| Zen 模式 | `⌘ ⇧Z` | `Ctrl+Shift+Z` |
| 快捷键帮助 | `⌘ /` | `Ctrl+/` |

### 命令面板补充

以下操作可通过命令面板访问：

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| 事件日志 | `⌘ J` | `Ctrl+J` |
| 广播输入 | `⌘ B` | `Ctrl+Shift+B` |
| AI 对话 | `⌘ ⇧A` | `Ctrl+Shift+A` |

## 终端内

以下快捷键在终端窗格聚焦时生效：

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| 搜索 | `⌘ F` | `Ctrl+Shift+F` |
| 清屏 | `Ctrl+Shift+L` | `Ctrl+Shift+L` |
| 内联 AI 面板 | `⌘ I` | `Ctrl+Shift+I` |
| 关闭面板 | `Esc` | `Esc` |
| 复制 | `⌘ C` | `Ctrl+Shift+C`（或选中自动复制） |
| 粘贴 | `⌘ V` | `Ctrl+Shift+V`（或右键） |

:::note
`Ctrl+L` 留给 Shell 清屏并重绘提示符。应用自身的清屏操作在所有平台上均使用 `Ctrl+Shift+L`。
:::

## 分屏

| 操作 | macOS | Windows / Linux |
|------|-------|-----------------|
| 横向分屏 | `⌘ ⇧E` | `Ctrl+Shift+E` |
| 纵向分屏 | `⌘ ⇧D` | `Ctrl+Shift+D` |
| 关闭当前窗格 | `⌘ ⇧W` | `Ctrl+Shift+W` |
| 上一 / 下一窗格 | `⌘ ⌥ ←` / `⌘ ⌥ →` | `Ctrl+Alt+←` / `Ctrl+Alt+→` |

## SFTP

| 操作 | 快捷键 |
|------|--------|
| 上传 / 下载 | `→` / `←` |
| 全选 | `⌘ A` / `Ctrl+A` |
| 重命名 | `F2` |
| 删除 | `Delete` |

## 小技巧

- **命令面板**（`⌘K` / `Ctrl+K`）提供模糊搜索所有可用操作 — 忘记快捷键时使用它。
- **设置 → 快捷键**显示当前绑定及其生效范围。
- 部分终端聚焦快捷键在不同平台有差异，因为 OxideTerm 避免拦截常用 Shell 键位（如 `Ctrl+C` 用于 SIGINT）。
