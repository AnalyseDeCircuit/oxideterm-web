---
title: 本地终端
description: 原生 Shell 集成 — 无需 SSH 即可在本地机器运行终端会话，支持多 Shell 与跨平台。
---

OxideTerm 同时也是一个本地终端模拟器，让你在 SSH 连接旁边直接运行原生 Shell 会话。无需服务器或网络 — 打开标签页即可开始工作。

## 快速开始

### 创建本地终端

**快捷键**: `⌘T` (macOS) 或 `Ctrl+T` (Windows/Linux)

其他方式:
- 点击侧边栏的 **本地终端** 按钮
- 使用菜单 **File → New Local Terminal**
- 使用 **Shell 选择器** `⌘⇧T` / `Ctrl+Shift+T` 选择特定 Shell

在 Windows 上，Shell 选择器也会列出检测到的 WSL 发行版。选择发行版即可打开对应终端。

## Shell 检测

OxideTerm 会自动扫描系统中可用的 Shell。各平台支持情况如下：

### macOS

| Shell | 路径 | 说明 |
|-------|------|------|
| **Zsh** | `/bin/zsh` | 系统默认 |
| **Bash** | `/bin/bash` | 内置 |
| **Fish** | `/opt/homebrew/bin/fish` 或 `/usr/local/bin/fish` | 需安装 |
| **Nushell** | `/opt/homebrew/bin/nu` 或 `/usr/local/bin/nu` | 需安装 |

### Windows

| Shell | 路径 | 说明 |
|-------|------|------|
| **PowerShell 7+** | `C:\Program Files\PowerShell\7\pwsh.exe` | 推荐 |
| **PowerShell 5.1** | `C:\...\WindowsPowerShell\v1.0\powershell.exe` | 内置 |
| **Git Bash** | `C:\Program Files\Git\bin\bash.exe` | 需安装 |
| **WSL** | `C:\Windows\System32\wsl.exe` | 推荐 |
| **命令提示符** | `C:\Windows\System32\cmd.exe` | 传统 |

### Linux

| Shell | 路径 | 说明 |
|-------|------|------|
| **Bash** | `/bin/bash` | 通用默认 |
| **Zsh** | `/usr/bin/zsh` | 需安装 |
| **Fish** | `/usr/bin/fish` | 需安装 |
| **Dash** | `/bin/dash` | 轻量级 |

Shell 扫描在 macOS/Linux 上读取 `/etc/shells`，在 Windows 上探测常见路径。

### 设置默认 Shell

1. 打开 **设置** (`⌘,` / `Ctrl+,`)
2. 进入**终端 → 本地**
3. 从下拉菜单中选择首选 Shell
4. 打开新的本地终端，使用刚选择的 Shell

### 自定义程序路径

在**设置 → 终端 → 本地**中选择 Shell，编辑或浏览选择它的可执行文件路径。这里填写程序路径，不是带参数的命令。重置可恢复自动检测；打开新终端后使用新路径。路径仅属于当前设备，不参与跨设备导出或同步。

同一页面还可设置默认工作目录、是否加载 Shell 配置、Oh My Posh 和环境变量。Shell 列表仍由平台扫描器发现，不读取 `shells.json`。

## Windows 增强功能

### 自动 UTF-8 编码

启用 Oh My Posh 后，PowerShell 会自动初始化 UTF-8 编码：

```powershell
[Console]::InputEncoding = [Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
```

确保中日韩字符、Emoji 和 Nerd Font 图标正确渲染。

### Oh My Posh 自动初始化

如果系统检测到 `oh-my-posh`，OxideTerm 会自动将其初始化注入 PowerShell 会话：

```powershell
oh-my-posh init pwsh --config '<your-theme-path>' | Invoke-Expression
```

**前提条件**：安装 Oh My Posh (`winget install JanDeDobbeleer.OhMyPosh`)、Nerd Font 字体，并在 OxideTerm 设置中选择该字体。

### WSL 环境变量

WSL 会话自动接收以下环境变量：

| 变量 | 值 | 用途 |
|------|----|----|
| `TERM` | `xterm-256color` | 终端类型 |
| `COLORTERM` | `truecolor` | 真彩色支持 |
| `TERM_PROGRAM` | `OxideTerm` | 终端程序标识 |
| `TERM_PROGRAM_VERSION` | 当前版本 | 版本信息 |
| `POSH_THEME` | 用户配置路径 | Oh My Posh 主题（自动转换 Windows 路径） |

## 多终端管理

每个本地终端标签页生成独立的 Shell 进程。你可以同时在不同工作目录运行不同 Shell：

```
终端 1: PowerShell  (C:\Users\alice)
终端 2: Git Bash    (C:\projects\app)
终端 3: WSL Ubuntu  (/home/alice)
```

结合 **分屏** 使用 — 每个窗格拥有独立的 PTY 进程。

:::note
关闭包含分屏的标签页时，OxideTerm 会递归清理窗格树中的所有 PTY 进程，不会留下孤儿进程。
:::

## 高级配置

### 启动选项

OxideTerm 会为已检测到的 Shell 使用默认启动参数。在**设置 → 终端 → 本地**中，你可以启用或禁用 Shell profile 加载、设置默认工作目录、配置 Windows 上的 Oh My Posh，并为新的本地终端会话添加自定义环境变量。

### Shell 初始化脚本

在 Shell 配置文件中检测 OxideTerm 以进行自定义配置：

**Zsh** (`~/.zshrc`):
```bash
if [[ "$TERM_PROGRAM" == "OxideTerm" ]]; then
    export PS1="%F{cyan}%~ %F{white}❯ "
fi
```

**Bash** (`~/.bashrc`):
```bash
if [[ "$TERM_PROGRAM" == "OxideTerm" ]]; then
    export PS1="\[\e[36m\]\w \[\e[0m\]❯ "
fi
```

**PowerShell** (`$PROFILE`):
```powershell
if ($env:TERM_PROGRAM -eq "OxideTerm") {
    function prompt { "$PWD> " }
}
```

## 故障排查

**Shell 未被检测到？**
使用 `command -v zsh`（Unix）或 `where pwsh`（Windows）确认程序存在。所选 Shell 安装在检测位置之外时，在**设置 → 终端 → 本地**中指定其路径。

**终端无法启动？**
确认所选 Shell 二进制文件仍然存在且可执行。选择另一个已发现的 Shell 后重试。

**输出乱码？**
使用 `echo $LANG` 检查 Shell 编码 — 应包含 `UTF-8`。如有需要设置 `TERM=xterm-256color`。如果图标字形损坏，安装 Nerd Font 字体。

**PowerShell 启动慢？**
PowerShell 启动时加载 `$PROFILE`。优化你的 profile 或使用 `-NoProfile` 启动。PowerShell 7 比 5.1 更快。

**WSL 连接问题？**
运行 `wsl --list --verbose` 检查 WSL 状态。确保已安装 WSL 2 并设置默认发行版（`wsl --set-default Ubuntu`）。
