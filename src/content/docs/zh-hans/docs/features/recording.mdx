title: 会话录制
description: 按 asciicast v2 格式录制终端会话、播放录制内容，并在返回历史时使用时间轴快速检索。
---

**会话录制**以标准的 asciicast v2 格式（`.cast`）捕获完整的终端会话，供后续回放和安全审计使用。

## 开始录制

1. 在工具栏或终端右键菜单中点击 **REC** 按钮
2. 录制立即开始——工具栏出现红色 ● 指示器和计时器
3. 正常使用终端；录制显示的输出，不直接记录按键。Shell 或程序回显的输入仍可能出现在输出中。


## 播放控件

打开已保存的录制文件后，播放器底部显示完整控件：

| 控件 | 功能 |
|------|------|
| ▶ 播放 / ⏸ 暂停 | 播放或暂停回放 |
| ⏹ 停止 | 停止并重置播放头到起始位置 |
| 时间轴拖拽 | 跳转到任意时间点 |
| 速度选择器 | 0.5× / 1× / 2× |

## asciicast v2 格式

录制文件以标准 asciicast v2 JSON 格式保存：

```json
{"version": 2, "width": 220, "height": 50, "timestamp": 1735000000, "title": "prod-server deployment", "env": {"TERM": "xterm-256color"}}
[0.123, "o", "$ "]
[0.456, "o", "ls -la\r\n"]
[0.789, "o", "total 48\ndrwxr-xr-x  5 user user 4096 Jan  1 12:00 .\n"]
```

该格式兼容 [asciinema](https://asciinema.org) 播放器及其他支持 asciicast v2 的工具。

## 录制管理

手动录制保存为所选位置的 `.cast` 文件，可通过文件管理器打开播放。

自动审计录制是独立流程：进入**通知与审计 → 审计**开启审计，再进入**会话录制**开启“录制终端输出”并确认提示。两个开关默认均关闭。刷新录制列表后可打开会话回放。

自动录制包含显示输出和终端尺寸变化，不包含直接按键或终端文件传输载荷；回显内容仍可能被记录。数据在本机加密保存，不参与云同步。默认保留 7 天、容量 2 GiB，可在页面中修改并保存。内容不完整或过期提示表示部分输出已无法回放。

## 录制内搜索

回放时按 **Ctrl+F**（macOS：**⌘F**）打开搜索框，在时间轴上高亮匹配的输出内容——快速定位特定命令或输出字符串。

## 停止 / 暂停 / 丢弃

| 操作 | 说明 |
|------|------|
| **暂停录制** | 暂时停止捕获，不结束录制 |
| **停止录制** | 完成并保存文件 |
| **丢弃录制** | 结束录制但**不保存** |

:::caution[隐私提示]
手动导出的 `.cast` 文件是明文，可能包含密码、API 密钥或其他敏感输出；自动审计录制则在本地加密保存。分享导出文件前应检查内容。
:::
