顶栏选择当前查看哪些标签，左侧管理连接和全局页面，右侧打开 OxideSens 和主机工具。

## 标签范围

顶栏中央的选择器支持搜索，包含**全部标签**、**全局页面**、**本地终端**和各个连接。某个连接的范围包含它的终端、文件、IDE、端口转发和绑定连接的插件页面。连接按身份区分，不会仅因地址相同而合并。

窗口在本次运行期间记住每个范围上次选中的标签；该标签已关闭时，选择同范围内的其他标签。范围为空时提供“全部标签”入口。范围选择不参与同步，也不跨重启恢复。

筛选只改变展示，隐藏的会话、传输和隧道继续运行。混合分屏出现在各窗格所属的范围中，始终保留完整布局。

## 打开与整理标签

主动打开页面时，会显示对应范围：设置进入全局页面，某个连接的 IDE 进入该连接范围。当前已经是全部标签时保持不变；后台更新不会切换范围。

前后切换、数字快捷键和批量关闭作用于可见标签。拖动只改变可见标签的相对顺序，不打乱隐藏标签。标题完整显示，放不下时横向滚动标签栏。页面在窗口间移动后，各窗口相应更新选中状态。

## 顶栏操作

- **命令面板：**搜索图标打开已有操作选择器。
- **禅模式：**隐藏外围导航，使用已配置的快捷键退出；提示跟随自定义绑定变化。
- **后台任务：**有后台工作时显示摘要，可定位相应任务。
- **主题：**太阳或月亮表示当前模式。在[外观设置](/zh-hans/docs/features/themes/)中配置明暗两套方案后，即可切换。

全屏保留顶栏，禅模式隐藏顶栏。Windows 和 Linux 的顶栏操作会为最右侧窗口控制按钮留出空间。

## 右侧工具

OxideSens 和各个[主机工具](/zh-hans/docs/features/host-tools/)在当前工作旁打开。经常变化的状态与按需查询的工具分组排列，只有高度不足时才出现“更多”。应用锁完成配置并在设置中开启入口后，显示在右侧底部；锁定不会停止连接。

范围选择器不决定命令目标。尤其在混合分屏时，应确认实际活动窗格或主机工具中选定的连接。

## 混合分屏

将标签拖入其他页面内容区的左、右、上或下边缘，在布局预览处松开。每个布局最多四个窗格，可组合终端、SFTP、IDE、设置、笔记和插件页面。再次打开单实例页面时，会定位原窗格；把布局移到另一窗口会保留会话。
