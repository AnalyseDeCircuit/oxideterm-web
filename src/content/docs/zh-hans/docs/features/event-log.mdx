---
title: 通知与审计
description: 检查操作历史、执行结果、关联会话和受保护详情的导出。
---

从活动栏打开**通知与审计**，或使用命令面板的事件日志操作。通知显示近期消息，**审计**、**会话**和**会话录制**提供历史与回放。

## 记录操作历史

1. 在**审计**中开启“启用审计”。默认关闭，开启后记录后续操作。
2. 执行要检查的连接、命令、文件或转发操作，返回后点击**刷新**。
3. 按类别、级别、来源、结果和时间筛选。选择搜索字段、输入内容后按 Enter。
4. 打开记录，检查目标、来源、结果和依据。“已发送”表示输入已送达；退出码或协议结果才能更明确地说明是否完成。
5. 在**会话**中查找同一会话的关联操作和录制。

时间筛选包含今天、本周、本月和保留的全部历史。搜索与筛选不会删除记录。当前连接状态和重连进度也可在[运行时](/zh-hans/docs/features/connection-monitor/)查看。

## 保留策略

关闭审计会停止新记录，但已有历史仍可阅读。操作记录默认保留 **90 天**，容量 **512 MiB**。在页面设置中修改保留时间和容量后保存；清空记录或缩短保留时间前，先导出需要保留的内容。

终端输出另有“录制终端输出”开关及确认提示，详见[会话录制](/zh-hans/docs/features/recording/)。仅打开审计页面不会自动记录输出。

## 导出

按当前筛选使用“导出摘要为 JSON”或“导出摘要为 CSV”。“导出受保护详情”需要确认，生成包含命令、路径、端点、账号和操作详情的明文文件，不包含会话录制。

分享前检查导出文件。失败操作的目标和结果依据有助于排障，凭据和无关私有内容不应进入支持报告。
