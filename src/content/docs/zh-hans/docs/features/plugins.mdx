打开**插件管理器 → 插件市场**安装所需功能，然后在插件管理器中启用。**RDP** 和 **VNC** 远程桌面由独立插件提供，安装后仍通过**新建连接**或**会话管理**打开桌面。详见[远程桌面](/zh-hans/docs/features/remote-desktop/)。

插件管理器也负责更新、设置、权限和卸载。每台需要这些功能的设备都应安装对应插件；同步连接配置不会自动安装插件。

## 通过插件安装的功能

| 功能 | 安装内容 | 使用入口 |
|---|---|---|
| Mosh 会话 | **Mosh** | 新建连接 → Mosh；远端还需安装 `mosh-server` |
| 更多代码语言 | 对应语言插件 | IDE 和代码预览 |
| PDF 页面 | **PDF Preview** | 文件管理器和 SFTP 预览 |
| SQLite 数据表 | **SQLite Preview** | 只读文件预览 |
| 证书检查 | **Certificate Viewer** | PEM / DER 证书预览 |

## 运行时模型

支持以下运行时：

- `process`：由宿主管理可执行文件，通过带版本的 JSON Lines 通信。
- `wasm`：由集成运行时管理 Wasm 模块。
- `manifest-only`：只声明贡献项，不需要可执行运行时。
- `remote-desktop`：为原生 RDP/VNC 查看器提供受信任的协议进程。
- `language`、`acp`、`terminal-transport` 和 `helper`：分别用于语言支持、AI 代理、终端传输和受管理的辅助程序。

原生应用不会执行旧的 JavaScript 入口。

## 安装和管理插件

使用桌面端“插件管理器”浏览、安装、启用、禁用、更新和配置插件。本地开发时，将插件包放入当前配置目录：

```text
<config-dir>/plugins/<plugin-id>/
├── plugin.json
└── plugin.wasm 或 bin/<executable>
```

运行 `oxideterm paths --json` 可查看当前配置目录。CLI 可以列出、启用、禁用插件并检查插件设置；安装和更新由桌面端管理器负责。

## 贡献项

插件可以声明标签页、侧栏面板、设置、命令、快捷键、上下文菜单、状态项、终端钩子、事件订阅、AI 工具和受支持的传输方式。标签页和面板提供声明式 schema，由 GPUI 负责渲染和交互。

## 安全

宿主会校验清单和路径，在激活时传入生效的能力与允许调用的宿主 API，并将插件诊断与协议输出分离。启用插件前，应检查其身份、权限、设置和声明的界面能力。
