---
title: 终端
description: 多标签页、分屏原生终端，支持 GPU 加速绘制、搜索、广播和会话录制。
---

OxideTerm 使用 **`alacritty_terminal` + GPUI** 实现原生终端。SSH、本地 PTY、Telnet 和串口的输入直接更新 Rust 中的终端状态，再由 GPUI 绘制到 GPU 表面；数据不经过浏览器脚本或本地网络桥接。

## 自适应渲染

终端会根据输入活动和待处理数据在三级策略之间自动切换：

| 级别 | 触发条件 | 作用 |
|------|---------|------|
| **Boost** | 上一轮未能排空待处理终端事件 | 提高单轮处理预算，尽快追上大输出 |
| **Normal** | 最近有键盘输入或终端活动 | 保持交互和滚动响应 |
| **Idle** | 一段时间没有终端活动 | 减少无意义重绘和资源消耗 |

渲染策略还会依据质量、平衡、性能或兼容配置调整事件排空预算、图片缓存和视觉效果。切换由 Rust 状态驱动，不依赖页面可见性或浏览器动画循环。

## 进程内数据流

终端与桌面界面之间没有线协议。典型 SSH 终端的数据流如下：

```text
SSH PTY 通道 → TerminalSession → TerminalState → GPUI 绘制
```

滚动缓冲、光标、选区、命令标记、搜索结果以及 Sixel/Kitty 图形都由 Rust 终端会话持有。窗口尺寸变化会直接更新会话并调整远端 PTY，无需跨前后端序列化。

## 多标签页与分屏

- 打开多个终端标签页，每个连接到不同或相同的 SSH 会话
- 支持**水平**和**垂直**分屏，实现并排查看
- 每个面板维护独立的 shell 通道
- 拖拽标签页重新排列或拆分为新面板

## 广播输入

广播会把终端键盘输入、粘贴文本和命令栏命令发送给选中的目标。目标可以位于其他标签或分屏中；目标组定义接收端，不会把组外终端隔离为独立发送端。切换到无关会话前应先关闭广播，详见[广播输入](/zh-hans/docs/features/broadcast/)。

## 终端搜索

搜索当前活动面板的原生终端滚动缓冲区。匹配结果会直接在终端画面中高亮，并支持上一个/下一个导航。当前实现使用区分大小写的字面文本匹配；搜索范围取决于配置的滚动缓冲行数。

使用 `Ctrl+Shift+F`（macOS 上为 `⌘F`）打开搜索栏。详细说明见[终端搜索](/zh-hans/docs/features/terminal-search/)。

## 会话录制与回放

录制终端会话以 **asciicast v2** 格式保存，供后续回顾：
- 捕获所有终端输出并精确记录时间戳
- 支持变速回放（0.5×–8×）
- 导出录制文件以分享或归档
- 兼容 [asciinema](https://asciinema.org) 生态

## 命令折叠与 Shell 集成

打开**设置 → 终端 → 显示**，启用**命令折叠**。点击已结束命令左侧的按钮，可收起或展开输出；命令右键菜单也提供“收起输出”或“展开输出”。需要在选中命令旁显示操作时，可开启“悬浮操作”。

左侧栏占一列字符宽度，终端内边距为 0 时也可使用。折叠只改变显示，不删除终端输出或录制内容。调整窗口大小后会保留已折叠的命令，并重新计算行位置。“命令标记”控制范围高亮，与折叠开关分开设置。

折叠需要 Shell 集成提供可靠的命令起点、输出起点和结束信息。仍在运行的命令、边界不完整的命令，以及已移出滚动缓冲区的输出不能折叠。仅打开显示开关，无法为旧输出补出缺失的命令边界。

### 安装或升级 SSH Shell 集成

1. 打开目标主机的 SSH 终端。
2. 进入**设置 → 终端 → 感知与集成**，检查远程 Shell 集成状态。
3. 按状态提示安装、更新或修复。部署策略可设为需要时询问、始终启用或不自动安装。
4. 完成后**新开一个 SSH 终端**。已打开的 Shell 仍使用原有钩子，更新文件不会自动重新加载。
5. 执行一条会输出多行并正常结束的命令，再尝试折叠。

打开新的 SSH 终端时，旧版远程集成可能触发更新提醒。选择“稍后”不会修改远端文件，之后仍可从同一设置页手动更新。

远程集成为 Bash、Zsh、Fish、Nushell 和 PowerShell 安装可读的钩子文件。更新并新开终端后仍无法折叠时，应检查实际使用的 Shell 及其启动文件是否加载集成；提示符主题和终端复用器也可能影响完整命令边界是否传到 OxideTerm。

## 命令面板

按 `⌘K`（macOS）或 `Ctrl+K`（Windows/Linux）打开 **命令面板**——快速访问 OxideTerm 中的任何操作，包括连接、设置、搜索和快捷键。

## 禅模式

进入**禅模式**可最小化干扰——隐藏侧边栏、标签栏和状态栏，让终端占据全部屏幕空间。

## 背景画廊

为终端自定义每个标签页的背景图片：
- 13 种支持的标签类型
- 可调整**透明度**和**模糊度**
- 多种适配模式（覆盖、包含、拉伸）

## 连接管理

- **会话树** — 以层级结构组织连接，支持文件夹和分组
- **快速连接** — 直接输入主机/用户名/端口进行连接
- **导入/导出** — `.oxide` 加密格式（ChaCha20-Poly1305 + Argon2id）
- **SSH Config 导入** — 自动解析 `~/.ssh/config` 导入现有连接
- **跳板机 / ProxyJump** — 无限跳数，网络拓扑图 + Dijkstra 寻路
- **认证方式** — 密码、SSH 密钥（RSA/Ed25519/ECDSA）、SSH Agent（跨 macOS、Linux、Windows 系统 Agent 支持）、证书、键盘交互 2FA
- **Known Hosts TOFU** — 主机密钥验证，兼容 `~/.ssh/known_hosts`；拒绝密钥变更（防止中间人攻击）
- **连接池** — 终端、SFTP、转发、IDE 通过引用计数连接池共享一个 SSH 连接
- **空闲超时** — 可配置（5m / 15m / 30m / 1h / 永不）；无消费者的连接超时后自动断开

## 本地终端

OxideTerm 还支持桌面平台的本地终端会话（PTY），基于 `alacritty_terminal::tty` PTY 后端。自动检测 Shell 类型：
- **macOS/Linux**：`zsh`、`bash`、`fish`、`pwsh`
- **Windows**：PowerShell 7、Git Bash、WSL2、CMD（原生 ConPTY——完整支持 TrueColor 和 ANSI，无传统 WinPTY）


## 资源与主机工具

活动 SSH 节点可以向原生监控和[主机工具](/zh-hans/docs/features/host-tools/)提供延迟、进程、服务、容器、端口、文件系统、软件包、日志及其他采样状态。它们与终端共享节点身份和重连状态，而不是打开一个无关的工作区。

## 选择与高亮控制

终端设置提供**按住 Shift 才能选择文本**选项。启用后，普通拖拽保留给终端交互，Shift + 拖拽才开始文本选择。

Shift + 点击可扩展已有选择；水平与垂直内边距可独立设置，默认均为 **1 px**；选中文本的相同项高亮同时提供全局设置，以及现有终端高亮面板中与 grep/rg 并列的控制入口。

## 文件传输协议

终端支持 trzsz，以及兼容 lrzsz 的 ZMODEM、XMODEM 和 YMODEM 工作流。协议数据先于显示转换和录制处理，检测到传输后通过传输界面完成或取消操作。

传输检测会等待完整的 trzsz 握手行，并避免把普通输出被截断后的尾部误判为 X/YMODEM 命令。
