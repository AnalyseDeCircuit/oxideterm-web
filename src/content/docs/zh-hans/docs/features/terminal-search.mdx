---
title: 终端搜索
description: 在原生终端滚动缓冲区中查找文本、高亮匹配并快速导航。
---

OxideTerm 直接搜索当前终端会话在 Rust 中维护的滚动缓冲区。搜索、匹配计数、滚动定位和高亮都由原生终端状态与 GPUI 界面完成。

## 打开搜索

| 平台 | 快捷键 |
|---|---|
| macOS | `⌘ F` |
| Windows / Linux | `Ctrl+Shift+F` |

也可以从终端右键菜单或命令面板选择“终端查找”。搜索栏会显示当前匹配位置和匹配总数。

## 搜索范围与匹配规则

- 搜索当前终端的可见内容和仍保留在滚动缓冲区中的历史内容。
- 当前实现执行区分大小写的字面文本匹配。
- 自动换行的逻辑行可以跨物理行匹配，宽字符和组合字符会映射回正确的终端单元格。
- 结果直接在原生终端画面中高亮；选择某个结果时，视图会滚动到对应位置。

当前终端搜索栏不提供正则表达式、整词匹配或独立的深度历史模式。可搜索的历史长度由终端滚动缓冲设置决定。

## 导航

| 操作 | 方式 |
|---|---|
| 下一个匹配 | `Enter` 或向下箭头按钮 |
| 上一个匹配 | `Shift+Enter` 或向上箭头按钮 |
| 关闭搜索 | `Esc` 或关闭按钮 |

到达最后一个结果后会回到第一个结果；向前越过第一个结果时会跳到最后一个结果。

## 使用建议

- 搜索日志中的完整错误标识、主机名或命令片段，可以减少字面匹配产生的无关结果。
- 找不到较早的输出时，请检查“设置 → 终端”中的滚动缓冲行数；已经被缓冲区淘汰的内容无法恢复。
- 搜索的是当前活动面板。分屏中的其他终端拥有各自独立的缓冲区和搜索状态。
