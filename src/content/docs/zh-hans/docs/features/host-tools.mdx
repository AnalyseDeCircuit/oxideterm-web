---
title: 主机工具
description: 不离开工作区，即可检查和操作 SSH 连接背后的远端主机。
---

**主机工具**是活动 SSH 连接的伴随面板。它位于工作区右侧，而不是运行时中的又一个分段，因此你可以在保持终端、SFTP 或远程桌面焦点的同时检查远端主机。

从活动栏打开**主机工具**。先在面板的连接选择器中选择活动 SSH 连接，再从横向工具栏选择工具；面板较窄时，工具栏可以横向滚动。

## 共享连接上下文

主机工具使用的正是工作区其余功能正在使用的受管理 SSH 连接。切换所选连接只会切换被采样的远端主机，不会额外打开一条无关的管理通道。

大多数工具都需要活动连接，以及远端主机上相应的命令或服务。因此，数据是否可用取决于操作系统、权限和已安装的软件。运行时仍负责汇总连接池状态、健康历史和连接矩阵。

## 可用工具

| 工具 | 提供的能力 |
| --- | --- |
| 监控 | 所选主机的资源与连接健康信息。 |
| 进程 | 可搜索、筛选的进程列表，包含进程详情和受支持的控制操作。 |
| 服务 | 服务清单、状态、日志和受支持的生命周期操作。 |
| 日志 | 远端日志快照、筛选，以及在终端中跟随或诊断的操作。 |
| tmux | tmux 会话、窗口和窗格，以及附加和受支持的管理操作。 |
| Docker | 容器状态、详情、日志、终端命令和受支持的生命周期操作。 |
| 端口 | 已发现的监听端口、筛选、详情和诊断终端操作。 |
| 计划任务 | 计划任务清单、状态、日志和受支持的立即运行或启停操作。 |
| 磁盘 | 文件系统快照、容量详情、筛选和诊断终端操作。 |
| 包管理 | 已安装软件包清单、筛选、详情和在终端中检查软件包。 |

## 远端操作

改变状态的操作会通过当前 SSH 连接在所选远端主机上执行。停止进程、改变服务或容器状态、删除 tmux 资源、修改计划任务等具有破坏性或生命周期影响的操作，OxideTerm 会先显示确认对话框。

账号缺少权限、远端没有相应工具，或连接已经中断时，命令仍可能失败。主机工具会在自己的面板中显示结果；需要查看完整命令输出，或执行当前控件未覆盖的操作时，请使用终端。

## 与运行时配合

**运行时**用于查看连接池和当前 SSH 拓扑；主机工具用于检查所选主机本身。排障时可以同时打开两者：运行时和[事件日志](/zh-hans/docs/features/event-log/)解释连接生命周期，主机工具则展示可能影响工作负载的进程、服务、日志、端口及其他远端状态。
