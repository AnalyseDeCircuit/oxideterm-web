---
title: 广播输入
description: 将终端输入和命令栏命令发送给选中的终端目标。
---

**广播输入**会将受支持的键盘输入、粘贴文本和命令栏命令发送给选中的终端目标。目标可以位于不同标签页或分屏中。

## 选择目标

在终端命令栏打开广播控制，启用广播，并通过目标选择器或已保存的广播组选择接收会话。输入前核对界面显示的目标。

这里选择的是**接收端**，不是一组封闭的发送端。广播启用时，即使当前终端不在目标组内，其输入也可能被发送给选中的接收端；来源面板会被排除，避免重复发送给自己。

## 广播组的行为

当前实现使用一组生效的广播目标。保存的广播组用于快速恢复目标选择，不会建立多条相互独立的同步通道。不能假定切换标签就能隔离输入，也不能假定基于连接的分组始终能独立选择同一保存连接下的两个 Shell 面板。

只需修改一台主机时，先关闭广播再输入；确认所有目标就绪后再启用。关闭面板会将它移出当前可用目标集合。

## 终端与命令栏

直接在终端画面中键入的内容也会广播，并非只有命令栏提交才会发送。各目标通过自己的终端会话接收输入，再按当前 Shell 或应用状态处理；目录、提示符或编辑器位置不同，同一输入的结果也可能不同。

:::caution
广播输入会立即发送。进入无关会话、输入凭据或执行仅针对单台主机的修改前，应先关闭广播。选择广播组不会限制哪些终端可以作为发送端。
:::

广播可与[终端分屏](/zh-hans/docs/features/terminal/)配合，在提交共同检查或部署命令时观察各目标输出。
