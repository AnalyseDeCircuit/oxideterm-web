---
title: 广播输入
description: 从终端命令栏向多个 SSH 和本地终端面板发送同一条命令。
---

**广播输入**会把终端命令栏中的一条命令发送到多个终端面板，适合机群部署、跨环境检查和多节点维护。

## 启用广播输入

1. 点击终端命令栏中的**广播**图标，或按 `⌘B`（macOS）/ `Ctrl+B`（Windows/Linux）
2. **广播目标**菜单会显示其他已打开的终端面板
3. 逐个选择面板，或使用**全选**
4. 从命令栏提交一条命令

命令栏会显示当前启用的广播目标数量。

## 目标选择

- SSH 会话会显示主机名
- 本地终端面板会标记为“本地终端”
- 提供**全选**和**全部取消**操作
- 显示当前面板和启用的目标数量
- 当前面板始终会收到提交的命令

:::note
同一组广播目标可以混合受支持的本地和远程终端面板。
:::

## 工作方式

广播启用后：

- 命令栏把提交的命令行发送给当前面板和每个选中的目标
- 每个面板通过自己的原生终端会话对象接收命令
- 每个目标独立执行命令
- 目标可以位于不同分屏位置或标签页

直接在终端画面中键入的内容**不会逐键镜像**。广播命令请使用终端命令栏提交。

## 停止广播

打开广播目标菜单，逐个取消选择面板，或使用**全部取消**。

关闭目标面板后，它会自动从当前目标集合中移除。广播没有永久指定的发送端；每次提交命令时，当前活动面板就是该命令的来源。

## 使用场景

- **机群部署** — 同时在 10 台服务器上运行 `sudo systemctl restart myapp`
- **环境一致性检查** — 在开发、预发布和生产环境运行 `env | grep APP_`
- **同步查看日志** — 同时执行 `tail -f /var/log/app.log`
- **配置发布** — 在多个节点上处理同一路径的配置文件
- **集群维护** — 向多个 Kubernetes 节点提交维护命令

:::caution
广播会把提交的命令**立即**发送给所有目标，不会额外弹出广播确认。执行破坏性命令前，请确认每个目标都处于预期的目录和 Shell 上下文。
:::

## 与分屏配合

广播可以和[终端分屏](/zh-hans/docs/features/terminal/)配合使用。你可以让一组 SSH 面板接收同一条提交命令，同时查看每个目标的输出。
