---
title: IDE 模式
description: 基于 GPUI 和 tree-sitter 的原生远程文件编辑，支持语法高亮和文件树导航。
---

IDE 模式让你直接在 OxideTerm 中编辑远程文件——无需下载、本地编辑再重新上传。所有操作通过现有 SSH 连接完成。

## 选择文件访问方式

打开 IDE 时，选择 **SFTP** 或 **SSH**。SFTP 使用连接的文件传输服务；SSH 可选择**纯 Shell 命令**，或按需安装、更新、复用代理。

纯 Shell 使用所选环境中的 Linux 工具，包括 GNU 文件与搜索工具，不安装代理；搜索有执行时间和结果数量边界。代理在支持的 Linux 主机上额外提供文件监控和符号服务。

如果已在终端中进入容器或通过 `su` 切换用户，可在空闲提示符处选择**转换为 IDE**，沿用当前用户、环境和目录，而不是另开登录环境。转换期间暂停终端输入，也可以返回原终端。

## 原生编辑器

编辑器由 Rust 与 GPUI 实现，并使用 **tree-sitter** 提供结构化语法能力，支持：
- 内置语言和已启用语言插件提供的语法高亮
- 行号和代码折叠
- 支持区分大小写、正则表达式、捕获组替换和全部替换
- 查找与替换支持多行粘贴和显式插入换行
- 括号匹配和自动闭合
- 缩进参考线
- 自动换行与原生选择、复制和撤销操作

IDE 与 SFTP 编辑器共用搜索栏。点击换行操作可插入换行，Enter 和 Shift+Enter 切换匹配。查找与替换输入框的编辑历史独立。拖动选区越过编辑器上、下边缘时，文档会自动滚动。

### 支持的语言

常用 Shell 和配置语言由应用内置，包括 Bash、Zsh、Fish、PowerShell、Python、JSON、YAML、TOML、SQL 和 Markdown。Rust、Go、C/C++、JavaScript、TypeScript 等语言通过语言插件提供。

在**插件管理器 → 插件市场**中查找所需语言，安装并启用对应插件。没有语言插件时，文本文件仍可打开和编辑；语法高亮以及依赖语法分析的折叠等功能，需要对应语法支持。安装远程 Agent 不会安装本机语言插件。

## 文件树

侧边栏文件树提供远程文件系统导航：
- **懒加载目录** — 仅在展开时加载目录内容，适合大型远程文件系统
- **Git 状态指示器** — 文件显示已修改 (M)、未跟踪 (?)、已添加 (A) 状态和颜色标记
- **事件驱动刷新** — 文件树在保存、创建、删除、重命名和终端 `Enter` 按键时自动刷新
- 点击打开文件到编辑器
- 通过右键菜单创建、重命名和删除文件及目录
- 基于扩展名的文件类型图标，便于快速识别

## 保存与同步

- 文件通过所选的 SFTP、纯 Shell 或代理方式保存回远程服务器
- **乐观 mtime 锁定** — 覆盖前，OxideTerm 检查远程文件的修改时间是否在加载后发生变化。如果发生变化，冲突对话框会出现，让你选择覆盖、重新加载远程版本或查看差异。
- 未保存的更改在标签上以圆点标识
- `Ctrl+S` / `⌘+S` 保存

## 多标签编辑

在标签页中打开多个文件，支持 **LRU（最近最少使用）标签管理**：
- 切换标签时不会丢失编辑器状态（光标位置、滚动位置、撤销历史）
- 达到最大标签数时，最近最少使用的标签会自动关闭
- 未保存的文件永远不会被自动关闭——它们受 LRU 逐出保护

## 远程 Agent（可选）

选择 **SSH → 使用代理**后，OxideTerm 可在所选环境的 `~/.oxideterm/oxideterm-agent` 安装、更新或复用代理，并显示安装进度。内置二进制支持 Linux `x86_64` 和 `aarch64`。代理通过现有 SSH 会话交换请求和响应，不监听额外网络端口。

### Agent 提供的功能

- **更快的文件树操作** — 目录列表、文件搜索和符号解析在远程主机上原生运行
- **实时文件监控** — 外部变更（来自其他编辑器或进程）立即反映
- **符号搜索** — 跨项目查找定义和引用
- **受版本约束的请求协议** — 提供文件、目录、Git、监控和符号相关操作

### 部署

- 在 x86_64 和 aarch64 Linux 上，确认启用 Agent 后可一键部署
- 其他架构需要自行从源码构建 Agent，再手动上传到远程主机
- Agent 二进制文件存储在远程服务器上，重连后仍然保留
- 可从 IDE 面板**一键删除**

### 无 Agent 模式

IDE 模式无需代理即可浏览和编辑文件。根据打开时的选择，文件树和读写通过 SFTP 或纯 Shell 完成；实时文件监控、符号索引等代理功能不可用。

## 与终端集成

IDE 模式与终端并行运行——在终端和编辑器标签之间无缝切换。通过连接池共享同一个 SSH 连接，无额外连接开销或认证提示。

## 重连行为

IDE 与终端、SFTP、端口转发共享节点身份。SSH 重连替换底层连接后，IDE 可以重新取得远程文件系统会话，保持项目路径与可见节点的关联。

打开的编辑缓冲区和未保存状态保留在本地工作区。节点不可用时暂停远程 I/O；只有取得有效的远程文件系统会话后才恢复读写。

:::tip
IDE 模式适合在远程服务器上进行快速编辑。对于需要索引、调试或扩展的大型项目，建议使用带有远程扩展的全功能 IDE。
:::

## 文件大小、编码与换行

IDE 使用独立的 **100 MiB** 文件编辑上限，不再依赖 SFTP 预览上限。Agent 和 SFTP 两种编辑后端都适用。

打开文件时识别编码、字节顺序标记（BOM）和换行格式。编辑器内部统一使用 LF，包括粘贴的文本；保存时按选定的编码、BOM 和 LF/CRLF/CR 格式写回。现有状态栏提供编码与换行入口，可以查看检测结果、按指定编码重新打开，或更改后续保存格式。

按指定编码重新打开会从磁盘重新读取文件，操作前应处理未保存的修改。
