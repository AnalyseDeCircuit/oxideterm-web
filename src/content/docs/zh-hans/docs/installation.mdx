## 系统要求

OxideTerm 是 GPU 加速的原生桌面应用。请使用带有可用图形驱动的桌面环境；应用不依赖 WebView，也不需要单独安装浏览器运行时。

| 平台 | 架构 | 发布形式 |
|---|---|---|
| **macOS** | Apple Silicon、Intel x64 | `.dmg`、`.app.zip`、便携压缩包 |
| **Windows** | x64、ARM64 | NSIS `.exe`、便携 `.zip` |
| **Linux** | x64、ARM64 | AppImage、`.deb`、便携 `.tar.gz` |

安装包通常约为 **50–70 MB**，具体大小会随平台和版本变化。

## 下载

从 [GitHub Releases](https://github.com/AnalyseDeCircuit/oxideterm/releases/latest) 下载与你的操作系统和处理器架构匹配的文件。

### macOS

1. 打开下载的 `.dmg`，将 **OxideTerm** 拖入“应用程序”。
2. 首次启动如果被 Gatekeeper 阻止，请在“系统设置 → 隐私与安全性”中确认打开。
3. 对于未经公证的预览构建，可以在确认下载来源后运行 `xattr -cr /Applications/OxideTerm.app` 移除隔离标记。

### Windows

运行对应架构的 NSIS `.exe` 安装程序，或解压便携版后直接启动 `OxideTerm.exe`。

### Linux

Debian/Ubuntu 可以安装 `.deb`：

```bash
sudo dpkg -i OxideTerm_*.deb
```

AppImage 需要添加执行权限：

```bash
chmod +x OxideTerm_*.AppImage
./OxideTerm_*.AppImage
```

如果程序无法创建图形表面，请先更新 GPU 驱动，并在设置中选择兼容渲染配置。从源码排查时，也可以使用 `OXIDETERM_RENDER_PROFILE=compatibility cargo run` 启动。

## 从源码运行

仓库使用 Rust 2024 Edition。发布流水线当前使用 Rust 1.94.1；建议通过 `rustup` 安装相同或更新的稳定工具链。

```bash
git clone https://github.com/AnalyseDeCircuit/oxideterm.git
cd oxideterm
cargo run
```

Linux 还需要 GPUI、音频、字体、窗口系统和媒体相关的系统开发包。仓库提供统一安装脚本：

```bash
./scripts/install-linux-deps.sh
```

构建优化后的桌面二进制和无头 CLI：

```bash
cargo build --release -p oxideterm-gpui-app
./scripts/build-cli.sh
```

桌面二进制位于 `target/release/`，CLI 会同时暂存到应用资源目录，供原生安装包包含。

## 配置与卸载

卸载应用前，可以用 CLI 查看当前配置和数据路径：

```bash
oxideterm paths --json
```

删除应用不会自动删除这些用户数据或系统凭据管理器中的凭据。需要完全清理时，请先确认 `paths` 输出，再删除对应目录和凭据管理器中的 OxideTerm 条目。
